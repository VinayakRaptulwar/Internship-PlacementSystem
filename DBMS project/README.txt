# College Internship & Placement Management System

## Project title to submit
College Internship & Placement Management System

## Files
- `DBMS_PBL_Project_Report.pdf` — ready-to-edit project report
- `internship_placement_system.sql` — MySQL database creation, sample data and queries
- `ER_Diagram.png` — ER diagram
- `README.txt` — execution instructions

## How to run
1. Install/open MySQL Workbench or another MySQL 8.x client.
2. Open `internship_placement_system.sql`.
3. Execute the complete script.
4. The database `internship_placement_db` will be created.
5. Run the demonstration queries at the bottom to show outputs.
6. Put your name, roll number and division in the PDF report before submission.
